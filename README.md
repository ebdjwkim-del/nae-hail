# 내 할일 v5 업데이트

프로젝트별 진행률과 날짜별 진행 기록을 관리하는 웹 앱입니다.

## 실행
GitHub Pages에서 배포한 뒤 HTTPS 주소로 접속하세요.

## 주요 기능
- 프로젝트 최대 20개 관리
- 프로젝트 개념 및 관련 인물 정리
- 날짜별 진행 기록과 진행률 입력
- 날짜별 기록 상세 보기 및 삭제
- 결과물, 성과, 종료일 및 성공/실패 정리
- JSON 백업 및 복원

## 데이터 및 보안 안내
현재 버전은 브라우저 로컬 저장소를 사용합니다. 실제 회원 인증, 관리자 권한 보호, PC·Android 간 자동 동기화에는 별도 서버와 데이터베이스 연결이 필요합니다.
